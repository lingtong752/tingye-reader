# 听页

听页是一款本地优先的免费阅读与听书工具。书籍和阅读进度保存在当前浏览器中，听书直接使用设备自带的系统语音，无需账号或额外服务。

## 功能

- 导入 `TXT`、`EPUB`，自动识别 TXT 章节与 EPUB 书名、作者、封面
- 书架搜索、最近阅读、章节目录与阅读进度保存
- 字号、字体、行距、页面宽度、纸张/纯白/夜间主题
- 语义分句朗读、当前段落高亮、播放暂停、上下段、倍速、声音选择
- 沉浸、自然、清晰三种讲述方式，按标点与上下文自然调整语气和停顿
- 章节连续朗读、10/20/30/60 分钟定时停止
- 桌面与手机响应式界面、离线应用缓存

## 技术栈

- React 18、TypeScript、Vite
- IndexedDB 保存书籍与阅读进度
- Web Speech API 提供设备语音朗读
- JSZip 解析 EPUB

## 本地运行

```bash
npm install
npm run dev
```

默认打开 `http://127.0.0.1:4173/`。

## 验证

```bash
npm run check
```

## 使用说明

1. 在书架点击“导入书籍”，选择自己合法持有的 `.txt` 或 `.epub` 文件。
2. 打开书籍后，点击底部播放按钮开始听书。
3. 点击右下角听书设置，可切换讲述方式、设备声音和定时停止。
4. 部分手机浏览器会在锁屏后暂停网页语音，这是浏览器系统限制；保持页面前台或把应用添加到主屏幕可获得更稳定的体验。

## 隐私与兼容性

- 书籍正文保存在浏览器 IndexedDB 中，不会因朗读上传到服务器。
- 语音种类由操作系统与浏览器提供，不同设备可用声音会有所不同。
- 推荐使用最新版 Chrome、Edge 或 Safari。
- 清除浏览器站点数据会同时清除本地书籍和阅读进度。
